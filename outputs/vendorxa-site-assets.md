# VendorXa Site Assets

Startup: VendorXa
Domain: vendorxa.com
Category: vendor lifecycle governance for procurement, legal, finance, security, and compliance teams.

## Logo Concept

The VendorXa mark is a vendor lifecycle dossier: two overlapping records connected by four checkpoint nodes. The crossing lines create a subtle X for the new name while representing the platform's job of connecting onboarding, risk, contracts, compliance owners, and renewals in one governed workflow.
